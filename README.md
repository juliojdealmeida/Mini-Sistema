Mini Sistema de Portfólio de Investimentos

📌 Objetivo

Este projeto foi desenvolvido como parte da disciplina Programação Orientada a Objetos II. O objetivo é criar uma aplicação de console em C# que simule um portfólio de investimentos simples, aplicando conceitos fundamentais da programação orientada a objetos.

🛠️ Funcionalidades

Inserir dados de novos investimentos.

Listar investimentos cadastrados.

Calcular valores totais do portfólio.

Simular rendimentos.

Exibir relatórios no console.

🧩 Conceitos Aplicados

Abstrações e Interfaces

Herança e Polimorfismo

Encapsulamento

Coleções genéricas (List, Dictionary)

Tratamento de exceções
